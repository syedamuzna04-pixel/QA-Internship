# Assignment 02 – Online Book Store Testing

## Overview

This assignment demonstrates the complete manual testing process for an **Online Book Store Web Application**. The objective was to create a structured testing workflow, organize test cases in Testworthy, execute test cases, and generate test execution reports.

---

## Objectives

The assignment included the following tasks:

- Create a High-Level Test Plan
- Design comprehensive manual test cases
- Organize test suites and sections in Testworthy
- Execute test cases
- Record execution results (Pass, Fail, Blocked)
- Generate a Test Execution Report

---

## Project Scope

The following modules were tested:

- User Registration
- Login & Authentication
- Browse Book Catalog
- Search Books
- View Book Details
- Shopping Cart
- Checkout Process
- Order Confirmation
