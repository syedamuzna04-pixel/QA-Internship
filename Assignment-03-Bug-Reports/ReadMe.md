# Assignment 3 – Bug Reporting

## Overview

This folder contains the deliverables for **Assignment No. 3 – Bug Reporting** completed as part of my QA Internship.

The objective of this assignment was to practice exploratory testing, identify functional and UI/UX defects, document bugs using a structured bug reporting format, assign severity and priority levels, and prepare release notes summarizing the identified issues.

## Applications Tested

The following demo web applications were explored:

- ParaBank
- OpenCart
- OrangeHRM
- Buggy Cars Rating

## Testing Areas

The applications were explored for issues related to:

- Navigation
- Forms
- Buttons and links
- Input validation
- Functional behavior
- Error handling
- UI/UX
- Usability
- Page navigation and redirects

## Deliverables

### Bug Reports
The Excel workbook contains documented bug reports with the following fields:

- Bug ID
- Application
- Title / Summary
- Description
- Steps to Reproduce
- Expected Result
- Actual Result
- Severity
- Priority
- Environment
- Status

### Release Notes
A release notes section is included in the workbook summarizing:

- Total bugs reported
- High-severity issues
- Major functional problems
- Overall system quality observations

## Testing Approach

Exploratory testing was performed by interacting with the applications, testing different inputs and workflows, and documenting unexpected or incorrect behavior that could be reproduced.
